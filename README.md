LANKA FRESH CORPORATE WEBSITE
=============================

CONTENTS
- index.html: complete one-page corporate website
- styles.css: responsive navy/ocean-blue/white styling
- script.js: mobile navigation and enquiry form behaviour
- assets/logo.svg: original scalable Lanka Fresh logo

PUBLISH FREE ON CLOUDFLARE PAGES
1. Create/sign in to a Cloudflare account: https://dash.cloudflare.com/
2. Open Workers & Pages, choose Create, then Pages.
3. Choose Direct Upload / Upload assets (wording may vary).
4. Upload the contents of this folder. Keep the assets folder and logo.svg in place.
5. Choose a project name such as lanka-fresh-seafood.
6. Deploy. Cloudflare will provide a free address like:
   https://lanka-fresh-seafood.pages.dev

This is a static website; no build command is required.
